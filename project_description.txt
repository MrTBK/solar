1. EXECUTIVE SUMMARY & DESIGN PHILOSOPHY
--------------------------------------------------------------------------------
The application is a production-grade personal portfolio engineered for
Mohamed Aziz Tabakh (Business Intelligence Student, Data Developer, Competitive
Programmer, and Robotics Trainer).

Rather than embedding a 3D canvas behind a standard web page, the entire
portfolio is conceptualized as an interactive 3D solar system inspired by
the exploration mechanics of Solar System Scope. The 3D universe is the primary
navigation interface:
- The Sun represents Mohamed Aziz Tabakh (System Core & Identity).
- Major engineering projects are distinct, interactive planets.
- Technical skills and sub-systems are represented as moons and satellites.
- Professional missions and academic institutions are modular orbital stations.
- Competitive programming achievements form a dense algorithmic asteroid belt.

Visual Theme:
"NASA Mission Control meets Modern Data Engineering and Premium 3D Graphics"
- Dark space aesthetic (#030712 deep navy background).
- Restrained cyan and electric blue accents, warm gold core for the Sun.
- Procedural textures generated directly via HTML5 2D Canvas shaders in memory,
  eliminating texture download delays and network failures.
- Zero audio asset dependencies: sounds are generated in real-time via the
  Web Audio API synthesizer.

3. DEEP DIVE: CORE THREE.JS & ANGULAR SERVICES
--------------------------------------------------------------------------------

A. CelestialFactoryService (celestial-factory.service.ts)
---------------------------------------------------------
Generates all 3D geometries, procedural canvas textures, and atmospheric shaders:
- createSunTexture(): Produces a 1024x1024 fiery radial gradient layered with
  400 procedural plasma flare granulations and sunspots.
- createSunGlowSprite(): An additive-blended radial flare sprite creating the
  Sun's pulsating coronal atmosphere.
- createPlanetTexture(type, baseHex): Dynamically generates unique surfaces:
  * "industrial" (DataForge): Dark slate bands, copper circuits, and pipeline traces.
  * "analytics" (Customer360): Sapphire continents with cyan coordinate grid lines.
  * "logistics" (SupplyChainIQ): Emerald landmasses with glowing shipping routes.
  * "mlops" (ChurnLab): Violet nebula gradients with illuminated neural synapses.
  * "finance" (Masroufi): Deep teal surface with golden latitude ledger rings.
  * "robotics" (Robotics): Burnt-orange modular mechanical plates and circuit traces.
  * "rock" (Asteroids): Craggy slate surface with impact crater shadows.
- createAtmosphereGlow(): Custom vertex/fragment ShaderMaterial implementing a
  Fresnel rim glow based on the view vector and surface normals.
- createSatelliteGroup(): Builds miniature satellites with metallic chassis,
  photovoltaic solar panels, blinking LED beacons, and orbital trace paths.
- createCoficabStationMesh(): Enterprise station model featuring a central
  cylindrical core, rotating docking ring, two solar array wings, and dish.
- createEducationStationMesh(): Gyroscopic orbital academy with an octahedral
  crystal core surrounded by dual rotating metallic rings.
- createAsteroidBelt(): InstancedMesh rendering 350+ randomized dodecahedral
  rocks, punctuated by 4 major glowing crystal landmarks (TCPC, Monopoly, etc.).
- createLabelSprite(): Camera-facing 2D canvas sprite rendering the body name
  and category in high-contrast HUD styling.

B. CameraService (camera.service.ts)
------------------------------------
Controls perspective, user interaction, and cinematic flight interpolation:
- Uses Three.js PerspectiveCamera and OrbitControls with smooth damping (factor: 0.05).
- flyTo(targetPosition, distance, elevation, trackedObj): Initiates a smooth
  quaternion and position transition using a cubic ease-in-out curve (easeInOutCubic).
- Dynamic Orbital Tracking: Once the camera arrives at a target planet, it locks
  onto the planet's world coordinates and smoothly tracks it in real-time as the
  planet continues orbiting the Sun.
- flyToOverview(): Smoothly restores the default overhead system angle (0, 75, 120)
  looking at the Sun (0, 0, 0).
- Clamps polar angles to prevent flipping underneath the system floor.

C. SolarSceneService (solar-scene.service.ts)
--------------------------------------------
Orchestrates the WebGL rendering pipeline:
- WebGLRenderer with ACESFilmicToneMapping and exposure calibration (1.25).
- Adaptive resolution: Limits device pixel ratio to 1.5 on mobile and 2.0 on desktop.
- Multi-spectral Starfield: 6,000 celestial points randomized across white, cyan,
  amber, and purple stellar spectra with exponential fog depth.
- Lighting System: A central PointLight inside the Sun radiating across planets,
  paired with AmbientLight (0x1e293b) and an elevated DirectionalLight rim fill.
- Central Animation Loop (requestAnimationFrame):
  * Advances orbital pivots according to state.orbitSpeedMultiplier().
  * Updates planetary self-rotations.
  * Updates satellite and moon revolutions around parent planets.
  * Pulses the Sun's coronal glow.
  * Drifts the asteroid belt and starfield.
  * Updates camera interpolation and renders the scene.

D. InteractionService (interaction.service.ts)
----------------------------------------------
Handles user input, raycasting, and coordinate projection:
- Tracks pointer coordinates and raycasts against solarScene.interactiveMeshes.
- Drag vs. Click Discrimination: Compares pointer-down and pointer-up distance;
  if the movement is under 6 pixels, it triggers an object inspection click.
- Hover Effects: Smoothly scales hovered bodies up by 8%, boosts emissive
  illumination, switches the cursor to pointer, and calculates 2D screen coordinates
  via worldPos.project(camera) to position the floating HUD tooltip.
- Keyboard Navigation:
  * ESC / Home / Space: Return to system overview / close modal.
  * 1 through 9: Direct jump to specific celestial bodies.
  * T: Toggle orbital path lines.
  * L: Toggle 3D planet labels.
  * M: Toggle audio sound effects.

E. AudioService (audio.service.ts)
----------------------------------
Pure Web Audio API procedural sound synthesizer:
- 0 audio files to download: runs entirely in real-time via oscillator nodes.
- playHover(): Rapid sine sweep (880Hz to 1320Hz, 60ms) for celestial hover blips.
- playSelect(): Futuristic two-tone harmonic ping (523Hz & 784Hz) on lock-on.
- playFly(): Low-frequency triangle wave sweep (140Hz to 420Hz) simulating a thruster whoosh.
- playToggle() & playClose(): Subtle acoustic clicks and dismissals.
- Persists user mute preference in localStorage ('solar_audio_muted').

F. StateService (state.service.ts)
----------------------------------
Central reactive state manager powered by Angular Signals:
- selectedTarget & hoveredTarget signals for active celestial bodies.
- activeModal signal ('project', 'about', 'skills', 'experience', 'education', etc.).
- activeProject computed signal resolving metadata from PROJECTS_DATA.
- Telemetry signal providing live sector focus, AU distance, and core temperature.
- Speed multiplier signal (0x, 1x, 2x, 5x) and layer toggles (orbits, labels).
- Deep-links and syncs state with Angular Router.

G. DeviceService (device.service.ts)
------------------------------------
Detects mobile screens (<768px), tablets, and hardware concurrency limits.
Checks WebGL context availability; if unavailable, seamlessly defaults to
the accessible 2D Schematic mode.


4. USER INTERFACE OVERLAYS & VIEWS
--------------------------------------------------------------------------------
1. CinematicIntroComponent: High-tech bootloader showing "MOHAMED AZIZ TABAKH",
   his core roles, and a simulated calibration progress bar before diving into 3D.
2. HudNavComponent: Minimal top HUD with active system indicators, direct view
   links (Skills, Experience, Honors, Education, About, Contact), HUD toggle,
   audio mute button, 2D/3D mode switch, and direct CV download button.
3. MissionControlComponent: Spacecraft telemetry console showing real-time AU
   distances, simulation speed toggles, layer visibility controls, and a radar jump list.
4. ProjectModalComponent: Responsive slide-out drawer (bottom-sheet on mobile)
   displaying project screenshots, Kimball star-schema details, pipeline
   architecture flows, metrics, tech stack pills, and GitHub source links.
5. Modal Views:
   - AboutModalComponent: Profile photo, mission directive, stats, coordinates.
   - SkillsModalComponent: Categorized capability constellation matrix.
   - ExperienceModalComponent: Career expeditions (Coficab, Youth Yes We Care, etc.).
   - EducationModalComponent: ESEN BI degree, Baccalauréat, and IBM certs.
   - CompetitionsModalComponent: High-res photo gallery of hackathons and ICPC qualifiers.
   - ContactModalComponent: One-click clipboard copy for email, LinkedIn, phone, CV.
6. Fallback2DComponent: Complete accessible 2D schematic system allowing full
   exploration on devices without WebGL support.

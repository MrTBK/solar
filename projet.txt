1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This project is an interactive 3D Solar System Orrery and Portfolio Web Application
built specifically to showcase the engineering identity, data systems, software
projects, professional career milestones, and technical mastery of Mohamed Aziz Tabakh.

Instead of a traditional flat web page or static CV, this portfolio transforms every
engineering achievement into a physically simulated, interactive celestial body:
- The central Sun embodies the developer's core identity, career summary, and ethos.
- The 5 Project Planets represent production-grade engineering applications, each
  orbited by autonomous satellites representing specific subsystem microservices
  (such as dbt Core nodes, Airflow schedulers, or MLflow registries).
- The 4 Career Stations & Belts represent professional missions, embedded hardware
  initiatives, national competitive programming tournaments, and university degrees.
- The 6 Skill Planets represent distinct technical domains with proficiency scores
  and direct skill breakdowns.
- The Black Hole Singularity represents an immersive secret event that devours the
  universe and opens an encrypted communication transmission channel.

The application achieves silky-smooth 60+ FPS rendering in WebGL, procedural Web
Audio synthesis, cinematic guided autopilot navigation, tactical 2D radar tracking,
and a recruiter gamification quest.


2. HOW THE SYSTEM WORKS (TECHNICAL ARCHITECTURE & ENGINES)
--------------------------------------------------------------------------------

A. FRONTEND ARCHITECTURE (Angular 22)
- Framework: Angular 22 with Standalone Components and Signals.
- State Management: Centralized reactive StateService managing active selected bodies,
  camera flight states, recruiter progress metrics, audio levels, and UI viewports.
- Lifecycle & Memory Safety: Explicit Three.js geometry/material disposal, event
  listener unbinding, and WebGL resource recycling on component destruction to prevent
  GPU memory leaks.
- Zero External Assets: High-performance design with no heavy external video or MP3
  assets. All soundscapes are procedurally synthesized in real time.

B. 3D GRAPHICS & SIMULATION ENGINE (Three.js)
- Three.js WebGL Renderer with logarithmic depth buffers, antialiasing, and tone
  mapping for deep space realism.
- Shaders & Materials: Custom emissive procedural shaders for the glowing solar corona,
  atmospheric planetary halos, planetary rings (Saturn-like dust discs), and particle
  dust fields containing thousands of distant stellar points.
- Orbital Mechanics & Galaxy Rotation: Every planet maintains its orbital distance and
  axial rotation. In addition, the entire planetary system rotates around the galactic
  core in unison to preserve clean visual alignments.

C. CAMERA TRACKING & ORBITCONTROLS DELTA-SYNC ENGINE
- Customized OrbitControls target synchronization: Solves the classic Three.js camera
  locking bug where OrbitControls fights against moving planetary meshes.
- In every render tick, CameraService calculates the position delta of the targeted
  celestial body and translates both the camera and controls.target by that exact vector.
  This allows the user to freely zoom out, rotate, pan, and inspect from any angle while
  remaining anchored to the moving planet.
- Navigation Ranges:
  * Minimum Zoom Distance: 2.0 AU (close-up surface inspection)
  * Maximum Zoom Distance: 1500.0 AU (macro-cosmic solar system overview)
  * Camera Far Frustum: 3500.0 AU (prevents any visual clipping of outer belts)

D. TRI-SECTOR RADIAL CORRIDOR LAYOUT
To make finding projects, work experiences, and skills intuitive, the planets are
arranged in three radial corridors separated by 120 degrees:

  1. PROJECTS CORRIDOR (Heading: -30 degrees):
     All 5 major software and data engineering projects aligned outward in a line:
     DataForge (20 AU) -> Customer360 (34 AU) -> SupplyChainIQ (48 AU) ->
     ChurnLab (62 AU) -> Masroufi (76 AU).

  2. WORK & CAREER CORRIDOR (Heading: +90 degrees):
     All professional and educational milestones aligned in a line:
     Coficab Mission (26 AU) -> Robotics System (44 AU) ->
     Algorithmic Ring (64 AU) -> Academia Orbital (84 AU).

  3. SKILLS CORRIDOR (Heading: +210 degrees):
     All 6 skill planets aligned in a line:
     Python & Data (22 AU) -> BI & DWH (34 AU) -> C++ & Algorithms (46 AU) ->
     Full-Stack (58 AU) -> Robotics & IoT (70 AU) -> Mobile & Offline (82 AU).

Because all planets in a corridor share synchronized orbital angular speeds, they remain
aligned directly behind each other as the galaxy rotates.

E. DUAL-MODE SKILL VISUALIZATION
The Skills sector features a dedicated toggle in the navigation HUD:
- 🪐 ALIGN ROW MODE: Moves the 6 skill planets out of orbit into a linear horizontal
  museum line along the X-axis (from X = -50 to X = +50), allowing side-by-side
  comparison of technical competencies.
- 🌌 3D ORBIT MODE: Returns the skill planets into their natural 210-degree radial
  corridor within the solar system.

F. GUIDED CINEMATIC AUTOPILOT TOUR
- An automated 16-stop cinematic journey flying seamlessly between every planet,
  satellite, industrial station, and academic outpost.
- Dynamic Scale Dampening: During tour flybys, planets are automatically scaled down
  to 0.55x (and the Sun to 0.65x) with elevated camera offsets. This prevents giant
  spheres from obstructing the camera viewport or covering data HUD telemetry.
- Voice & Narration: Integrates speech synthesis with real-time text narration, stop
  progress bars, speed multipliers (1x, 1.5x, 2x), and instant pause/resume controls.

G. TACTICAL 2D RADAR MINIMAP (ORRERY HUD)
- Located at the bottom-right corner of the screen.
- Renders an interactive polar radar display with real-time blips for every celestial
  body, color-coded by category (Emerald for Projects, Cyan for Work, Gold for Skills).
- Displays radial corridor guide rays and the camera's viewing frustum orientation.
- Clicking any blip on the radar immediately commands the camera to fly to that body.

H. PROCEDURAL WEB AUDIO SYNTHESIZER
- 100% code-synthesized audio via the Web Audio API without relying on external MP3s.
- Features:
  * Cosmic Ambient Drone: Low-frequency twin sine oscillators with gentle resonant
    filtering creating an authentic deep-space atmosphere.
  * Thruster Whoosh: Filtered pink noise bursts on camera warp acceleration.
  * UI Telemetry Beeps: High-frequency chime pings on buttons and modal interactions.
  * Gravitational Singularity Siren: Descending frequency sweeps during black hole
    vortex transitions.

I. RECRUITER QUEST SCANNER
- Gamified engagement system tracking recruiter exploration across 3 core sectors.
- Evaluates visited projects, inspects technical skills, and unlocks achievements:
  * "Architectural Explorer" (Visited all data engineering systems)
  * "Algorithmic Master" (Inspected competitive programming accolades)
  * "Singularity Pioneer" (Discovered the secret Black Hole)
- Provides quick-action buttons to download CV or initiate contact once milestones
  are reached.
